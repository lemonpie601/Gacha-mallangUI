## 1.12.0

스토리 SD 위치·크기를 고쳤습니다.

- 주인공이 혼자 가운데 서 있을 때 다른 인물이 등장하면, 주인공이 왼쪽으로 비켜섭니다. 이전에는 주인공이 가운데에 고정된 채 새 인물이 겹쳐 섰습니다.
- 등장인물팀이 한 명씩 늘어날 때 공간이 있으면 기존 인물은 오른쪽으로 조금 이동합니다. 공간이 없으면(화면 밖으로 밀리거나 절반 넘게 겹칠 때) 전체를 다시 배치합니다. 이전에는 4~5번째 인물이 오른쪽 끝(화면 밖)에 겹겹이 쌓였습니다.
- 처음 등장할 때 SD가 작게 나오던 문제: 테두리 입힌 그림이 준비될 때까지 기다렸다가(최대 1.5초) 등장합니다. 그 뒤에 그림이 도착해도 상자 비율을 실제 그림에 맞추며, 서 있는 위치는 바꾸지 않습니다. 이전에는 기본 비율 상자에 고정되어 넓은 그림(무기를 든 캐릭터 등)이 다시 등장할 때보다 작게 보였습니다.
- 말하던 인물이 장면에서 빠질 때 퇴장 애니메이션(0.34초 동안 흐려지며 살짝 내려감)이 나옵니다. 이전에는 퇴장 표시와 함께 등장 애니메이션을 끄면서 투명도가 첫 프레임에 0이 되어 바로 사라졌습니다.
- 선택지 크기를 게임 화면에 맞춰 키웁니다. 버튼 글자·높이·간격이 대사 글자와 같은 단위로 커지고 작아지며, 버튼 사이 간격을 넓혔습니다. 이전에는 px·화면 폭 고정값이라 작은 화면과 큰 화면에서 똑같이 작고 촘촘했습니다. 무대가 작으면 대사칸 위 남은 공간 안에서 스크롤합니다.
- 주인공 외 인원이 늘 때마다 주인공이 한 단계씩 왼쪽으로 이동합니다(1챕터 10 확인: 1명 31.7% → 2명 23.7% → 3명 17.1%). 이전에는 무대가 꽉 차면 주인공을 왼쪽 끝에 고정해서 2명·3명·4명일 때 위치가 같았습니다. 인원이 늘 때 기존 등장인물은 계속 오른쪽으로 조금 이동합니다.

1.11.11: 등장인물팀 2명의 중심 간격을 이전의 85%로 줄이고 팀 중심은 유지합니다. 3명은 오른쪽 추가 이동을 2%에서 2.5%로 조정합니다. 대사·발화 시 위치 유지와 애니메이션은 그대로입니다.

1.11.10: 등장인물팀 3/4/5명에서 오른쪽으로 2/4/6% 추가 이동합니다. 주인공팀에는 추가 이동을 적용하지 않으며, 대사 및 발화 변화로 배치를 재계산하지 않습니다.

1.11.10: 스토리 SD 배치·인원별 겹침·등장 및 발화 애니메이션을 1.11.2 원본으로 복원했습니다. 주인공 유지 및 생성 화면 사이드 미니게임 개선은 유지합니다.

생성 화면 안의 오른쪽 사이드 탭에서 미니게임을 엽니다. 별도 미니게임 로딩 팝업은 표시하지 않습니다. 생성이 끝나면 탭과 게임이 제거됩니다.

## 1.11.10 로딩 미니게임

챕터 생성·스토리 작성 로딩에서 지뢰찾기와 フルーツボックス를 선택할 수 있습니다. 두 게임 모두 난이도 선택과 크게 보기를 지원합니다. 난이도를 변경하면 새 판이 시작됩니다. 지뢰찾기는 쉬움 8×8·10개, 보통 10×10·18개, 어려움 12×12·30개이며 첫 클릭 주변은 안전합니다. 우클릭 또는 깃발 모드를 사용하세요. 깃발은 글꼴과 무관하게 빨간 모양으로 표시됩니다. 과일 상자는 사각형 안 숫자의 합이 10이면 지워집니다. 드래그하거나 두 모서리를 차례로 누르세요. 게임 점수는 해당 로딩 화면 안에서만 유지되며 본편 보상과 연결되지 않습니다. 생성 완료·실패 시 미니게임과 로딩 팝업이 함께 닫힙니다. 로딩 화면 닫기는 생성 요청을 취소하지 않습니다. 챕터 → 스토리 진입에 한해서 미니게임 없는 별도 전체화면 팝업으로 표시하며, 진입 완료 시 닫힙니다.

## 설정 (설정 왼쪽 목록의 **말랑 · UI · SD** 탭, 말랑을 켰을 때만 보임)

말랑 설정에는 **UI 설정**과 **SD 관리** 목록이 따로 표시됩니다.

- **말랑 색상**: 프리셋 5종(크림 코코아 · 딸기 우유 · 민트 초코 · 라벤더 · 밤하늘) + 색 8개(바탕 · 카드 · 글자 · 외곽선 · 강조 버튼 · 선택 표시 · 배경 1 · 배경 2) 직접 고르기, [글꼴 받기]
- **트릭컬 화면**: 전투 필드 · 편성/출격 캐릭터 · 홈 로비 · 홈 대표 카드 숨기기 · 출석 이벤트 켜기/끄기, **홈 로비에 둘 캐릭터 목록**
  - 홈의 **[✥ 배치] → [소실점 · 바닥]**: 소실점과 두 선의 가운데를 끌어 깊이를, 양끝을 끌어 폭을 맞춥니다. 편집 중 하단 메뉴는 입력을 받지 않습니다. 이동 범위와 원근값은 세계별로 서버에 저장됩니다.
- **스토리 · 전투 이미지**: 불투명 대화창 · 스티커 초상 · 말랑 움직임 · 스토리에 SD · 전투에 SD · 로딩 화면 켜기/끄기
- **SD 캐릭터 만들기**: 이미지 연결 고르기, 프롬프트 · 네거티브 · 크기, 캐릭터별 그리기/다시/지우기/**편집**, [없는 캐릭터 전부 그리기], **[대사 만들기 (AI)] · [없는 대사만]**
  - **편집**: 캐릭터가 **바라보는 방향**(왼쪽 · 정면 · 오른쪽)을 정하면 로비에서 걷는 방향, 스토리 · 전투에서 마주 보는 방향이 맞춰집니다. 그림에서 볼을 눌러 볼 위치(최대 2곳)와 볼 크기를 정하고, 그 자리에서 미리 당겨 볼 수 있습니다. 로비 대사 3개와 볼 꼬집기 반응을 직접 고칠 수 있습니다. 저장된 의상 목록을 읽어 의상 이름별 SD를 만들 수 있으며, 각 의상의 설명을 생성 프롬프트에 사용합니다.
  - **대사 만들기**: 이 세계의 AI 연결로, 가챠 포지에 저장된 각 캐릭터의 성격·설정을 보고 대사 3개와 꼬집기 반응 1개를 씁니다(한 번 호출로 전원).

## SD 캐릭터 만들기

- 엔진의 이미지 연결(기본값: 이 세계의 이미지 연결)로 그립니다. 요청마다 3~7초 무작위로 기다렸다가 보냅니다. 그릴 때마다 연결 사용량(NovelAI는 Anlas)이 듭니다.
- 기본 프롬프트: `4::chibi, chibi only::, solo, Transparent background, 1.2::full body::, shoes, standing, looking at viewer, {appearance}`
  - `{appearance}`는 가챠 포지 캐릭터 정보의 외형 묘사, `{name}`은 이름으로 바뀝니다.
- 그림은 Marinara 갤러리에 저장되고, 어느 캐릭터의 SD인지와 대사·볼 위치·방향·키·의상별 SD는 이 확장의 서버 저장소에 기록되어 다른 기기에서도 같이 보입니다.
- SD가 없는 캐릭터는 전투 · 편성에서 초상 스티커 카드로 나오고, 홈 로비에는 나오지 않습니다.

## 성능

SD의 흰 스티커 테두리는 처음 볼 때 한 번만 그림에 구워 두고(blob 이미지), 화면에서는 필터 없이 움직입니다. 로비 · 스토리의 움직임은 시계 기준으로 이어져서 게임이 화면을 다시 그려도 처음부터 다시 시작하지 않습니다. 로딩 화면은 0.35초 넘게 걸리는 로딩에만 뜹니다.

타자 출력의 글자 변경은 UI 전체 갱신을 일으키지 않습니다. 로비 캐릭터 노드를 재사용하고, 서신 팝업이 열리면 걷기를 멈춥니다. 볼 변형은 원본 해상도를 유지하며 볼 주변 영역만 갱신합니다. 게임 데이터·SD는 변경하지 않는 화면 이동으로 불필요하게 다시 불러오지 않습니다.

## 스토리 선택지와 등장인물

Gacha Choice가 실제 선택지(`gch-menu / gch-opt`)를 표시할 때만 말랑 캡슐 테마를 적용합니다. 선택지 기능이 없거나 선택지가 없는 대사에는 메뉴를 만들지 않습니다. 선택지·CG가 표시되는 동안 SD는 숨깁니다. 현재 장면에서 대사하거나 등장한 인물만 최대 3명 표시하고, 장소가 바뀌거나 이름과 함께 명시된 퇴장 서술이 나오면 목록을 갱신합니다. 문장만으로 표현된 모호한 퇴장은 자동 판정하지 못할 수 있습니다.

이 UI 확장은 **확장만으로 동작**하며 서버 패치를 설치하지 않습니다. 별도 Gacha Choice 확장의 선택지 생성 기능은 해당 확장이 요구하는 서버 패치에 따릅니다.

## 다른 기기 · Tailscale에서 쓸 때

Marinara 전용 `marinara.storage`로 서버에 저장하고, 구형 런타임은 CSRF 헤더를 붙인 API로 저장합니다. 빠르게 여러 값을 바꿔도 순서대로 저장해 오래된 요청이 최신 설정을 덮지 않게 했습니다. 다른 기기에서 변경한 SD·대사·설정은 창이 다시 활성화될 때와 활성 상태에서 30초마다 확인합니다. 배치 편집과 입력 중인 설정은 덮어쓰지 않습니다. 이전 버전에서 그린 SD는 갤러리에는 있지만 목록이 저장되지 않았을 수 있는데, 세계를 열면 갤러리에서 자동으로 되찾습니다(설정의 [갤러리에서 되찾기]로 직접 할 수도 있습니다). 저장이 실패해도 이 브라우저에 보관했다가 15초마다 다시 보냅니다.

## 저장되는 곳

| 무엇 | 어디 |
| --- | --- |
| 말랑 켜기/끄기 | 이 브라우저(localStorage) |
| 색상 · 옵션 · 프롬프트 · 홈 배치 | 이 확장의 서버 저장소(기기 간 공유), 이 브라우저에도 사본 |
| SD 목록 · 볼 위치 · 캐릭터 대사 | 이 확장의 서버 저장소 `sd:<세계 ID>` |
| SD 그림 | Marinara 갤러리 |
| 둥근 글꼴 | [글꼴 받기] → Marinara 글꼴 보관함(data/fonts) |

마리나라 페이지의 보안 정책(CSP)이 외부 글꼴을 막기 때문에, 글꼴은 Marinara 자체 글꼴 기능으로 받습니다. 받기 전에는 맑은 고딕으로 보입니다.

## 1.10.39 SD 편집창

SD 편집을 화면 크기에 맞춘 전용 창으로 변경했습니다. 왼쪽 그림을 유지하면서 볼·배치 / 의상·보관함 / 프롬프트 / 대사 탭을 전환합니다. 의상은 위쪽 선택 상자로 바꾸며, 보관함은 선택한 의상만 표시합니다. 대사 재생성 버튼은 해당 입력칸 옆에 배치했습니다. 닫기 버튼 또는 Esc로 돌아갑니다. 좁거나 낮은 화면에서는 내용 접근을 위해 편집 영역 내부 스크롤을 허용합니다.

## 1.10.40 로딩·퀘스트 UI

챕터 및 스토리 진입 로딩은 게임 내부 대신 별도 팝업으로 표시합니다. 전투와 일반 메뉴 로딩은 기존 위치를 유지합니다. 퀘스트 팝업에 기존 UI / 말랑 UI 선택 버튼을 추가했습니다. 기본값은 기존 UI이며, 말랑 선택 시에만 추가 스타일을 적용합니다. 기존 UI를 선택하면 추가 스타일을 제거합니다. 선택은 브라우저별로 보관하며 퀘스트 확장 원본 파일은 수정하지 않습니다.

## 1.10.41

- 챕터·스토리 진입 함수 실행 전에 전체 화면 로딩 팝업 표시. 연속 DOM 갱신이 안정된 후 닫습니다.
- 스토리 캐릭터 겹침 배치 복원
- 적 속성 배지를 카드 밖의 별도 표시 레이어로 이동
- Jua / Gowun Dodum / Noto Sans KR / Nanum Gothic / 기기 기본 글꼴 선택
- 저장 요청 전 동기식 브라우저 백업, 서버 최신 캐릭터 기록 병합, 확장 ID 참조 보정
- 새 SD 갤러리 기록에 세계 ID·캐릭터·의상 식별자를 저장하고 같은 세계의 기본 SD만 자동 복구
- 퀘스트 스타일 덮어쓰기 제거. 별도 퀘스트 0.15.0의 독립 말랑 화면을 사용합니다.

이미 섞여 저장된 이미지의 출처는 확정할 수 없어 자동 삭제하지 않습니다. 올바른 SD를 다시 선택하거나 생성하세요. 동시에 여러 기기에서 같은 캐릭터를 수정할 때는 최신 캐릭터 저장이 우선합니다. 실제 iPad 브라우저 종료·재접속 실증은 아직 하지 않았습니다.

## 1.10.42 퀘스트 원본 무수정 연동

말랑 UI만 업데이트합니다. 원래 퀘스트 확장 0.14.1을 함께 켜면 설정 → 화면 테마 목록 맨 끝에 말랑 항목을 추가합니다. 선택하면 별도 Shadow DOM 화면에서 퀘스트 내용을 표시하고 버튼·입력은 기존 확장에 전달합니다. 다른 테마 선택 또는 말랑 UI 끄기로 원래 화면이 복원됩니다. 월드별 선택은 말랑 UI 설정에 저장됩니다. 퀘스트 소스와 저장 데이터 형식은 수정하지 않습니다.

이전 별도 퀘스트 수정본 0.15.0은 필요하지 않습니다. 이미 설치했다면 사용자 제공 원본 0.14.1로 되돌린 후 이 말랑 UI를 사용하세요. 로컬 모의 데이터로 테마 위치·입력/액션 전달·화면 복귀 및 CSS 적용을 검사했습니다. 실제 서버에는 설치하지 않았습니다.
